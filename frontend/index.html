How it works (for jury)

Anchor creates issuer, deploys SAC for wSRC, calls set_admin(gateway). Gateway only mints after finality_registry verifies BLS12-381 or Groth16 BN254 proof via native host functions. Source chain is simulated (2-of-3 deterministic demo keys, valid G1/G2 points, and a development Groth16 fixture). Stellar-side controls require configured Testnet contracts; this checkout is not deployed. Lock → proof → mint, burn → unlock, plus 4 fault probes. High-water-mark nonce prevents replay with one row per sender. Gasless code is shown for the flow, but no live claim is made until a fresh unfunded Testnet account is verified.

Contracts: finality_registry (BLS + ZK), settlement_gateway (lock/mint/burn + HWM). Off-chain: source_simulator (Axum), relayer (Rust), frontend (this). Anchor: stellar.toml + /info. See README.md for full run instructions and intentionally simplified parts.
