About

What the anchor facade is for

The facade is the integration surface, not the trust anchor. It publishes the discovery document other people's software reads (/.well-known/stellar.toml), it serves the deployment manifest the receipts were written against, it exposes the read-only audit record, and it is the only place an operator can ask for a relayer pass.

It holds no custody, no mint authority and no verification keys. If it disappeared, settlement would keep working — you would lose the window, not the rule.

Is this a zkVM?

No. There is no virtual machine here. The Groth16 lane verifies one fixed statement compiled ahead of time: a quorum of approval bits is set and three roots participate in one Poseidon relation. It is a statement proof, not a VM proof, and a quorum proof, not a signature proof — which is exactly why settlement anchors on the BLS lane, whose signature does cover the event root.

The full write-up, including the measured on-chain cost, is in docs/PROVING_SYSTEM.md.
